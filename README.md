## 🚀 Getting Started

### 🔧 Installation

1. Clone the Airbnb-clone repository:
```sh
git clone https://github.com/GyanPrakashKumar/Airbnb-clone
```

2. Change to the project directory:
```sh
cd Airbnb-clone
```

3. Install the dependencies:
```sh
npm install
```

### 🤖 Running Airbnb-clone

```sh
npm run dev
```
